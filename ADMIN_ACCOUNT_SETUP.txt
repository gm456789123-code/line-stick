ADMIN ACCOUNT SETUP

Use only DEV account in .env:
CMS_DEV_USER=dev
CMS_DEV_PASS=dev123

Store these accounts in MySQL table `cms_admin_users`:
CMS_SUPERADMIN_USER=superadmin
CMS_SUPERADMIN_PASS=super123

CMS_ADMIN_USER=admin
CMS_ADMIN_PASS=admin123

CMS_EDITOR_USER=editor
CMS_EDITOR_PASS=editor123
